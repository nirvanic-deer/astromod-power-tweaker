
## Description

Tired of your RTGs not quite meeting your power needs ?  
Want your QT-RTG to outperform its bigger sibling ?
Or perhaps you'd rather have a challenge and make them both completely useless and provide ZERO power ?

RTG Power Tweaker lets you customize the power output of Astroneer's small and medium RTGs 
through an in-game configuration menu, with changes applied live !


## Requirements

⚠️ **WARNING** ⚠️
The in-game configuration menu relies on: 
[**AstroModLoader-Classic / AstroModIntegrator**](https://github.com/atenfyr/AstroModLoader-Classic/tree/master).

The configuration screen is a feature made available by: 
[AstroModLoader-Classic/AstroModIntegrator version v1.8.2.0+](https://github.com/atenfyr/AstroModLoader-Classic/blob/master/AstroModIntegrator/BlueprintAssets/README.md).

> Other mod-loaders may work, 
> provided they use a sufficiently recent version of 
> AstroModLoader-Classic / AstroModIntegrator under the hood. 

_You can always try to load the mod, and see if the configuration screen shows up._


## Main features

**Configurable power generation**
You can tweak the generation rate of both the small RTG (QT-RTG) and the medium RTG
to the values you want, easily.

**Live updates**
The changes apply as soon as you make them, without restarting/reloading anything.
You don't even have to quit the save you are on.

**Your rules**
Make the RTG and QT-RTG as OP or as bad as you want them to be.
The defaults should be x2 if I remember correctly.

**Vanilla power outputs**:
In case you want a refresher:
| RTG | Power generation |
|---|---:|
| Small RTG (QT-RTG) | 1 U/s |
| Medium RTG | 4 U/s |

Tune them to your liking !


### Installation instructions

1. Download the latest release archive: `RTGPowerTweaker-#.#.#.zip`.
2. Extract the archive to obtain the `.pak` file.
3. Install the `.pak` through AstroModLoader-Classic, or a compatible mod loader that uses AstroModIntegrator.
4. Launch Astroneer, open the configuration menu, and start tweaking your RTGs!
